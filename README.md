# 🚀 Formaciones Tech – De Cero a Entorno Profesional

Bienvenido al repositorio de formación para alumnos en prácticas.

Aquí no solo aprenderás teoría.  
Aquí vas a trabajar como se trabaja en un equipo real.

Este espacio está diseñado para que domines las herramientas esenciales del desarrollo moderno:

- 🐳 **Docker** – Entornos reproducibles y despliegue profesional  
- 🌿 **Git** – Control de versiones como en equipos reales  
- 📦 **npm** – Gestión de dependencias y scripts  
- ⚛️ **React** – Desarrollo moderno basado en componentes  
- 🅰️ **Angular** – Arquitectura estructurada para aplicaciones escalables  

---

## 🎯 Objetivo

Que pases de:

> “Sé programar un poco”

a

> “Estoy listo para trabajar en un equipo profesional”

---

## 🧠 ¿Qué vas a aprender aquí?

- Cómo funciona realmente un entorno de desarrollo moderno
- Cómo trabajar con ramas, pull requests y buenas prácticas en Git
- Cómo levantar proyectos con Docker como en producción
- Cómo estructurar aplicaciones frontend profesionales
- Cómo gestionar dependencias y scripts con npm
- Cómo pensar en arquitectura y escalabilidad

---
